## Performance

> Manual old-vs-new benchmark of the `--columnar` engine over the set in [`columnar_wip/benchmark-networks.md`](columnar_wip/benchmark-networks.md). This is **not** the CI `perf-pr.yml` check, which only sees the default OO path since the new core is flag-gated.

Single-threaded (`MODE=release OPENMP=0`), `--seed 123`. Codelength in bits. **`instr` is instructions retired** (`/usr/bin/time -l`). `time` is `--timing-json`'s `timing.total_s`.
- `-N10` rows run once (deterministic; `instr` carries the comparison).
- `-N1` rows are the interleaved minimum of 3.
- Driver: [`columnar_wip/bench-sync.py`](columnar_wip/bench-sync.py) `--carry-oo`, writing [`columnar_wip/refine-skip-ab-results.tsv`](columnar_wip/refine-skip-ab-results.tsv), old and new on every row of the #1398 snapshot.
- Re-timed: every configuration whose codelength changed, with [`columnar_wip/retime-changed.py`](columnar_wip/retime-changed.py), writing [`columnar_wip/refine-skip-retime-changed.tsv`](columnar_wip/refine-skip-retime-changed.tsv). The outliers in seconds, with [`columnar_wip/retime-outliers.py`](columnar_wip/retime-outliers.py), writing [`columnar_wip/refine-skip-retime.tsv`](columnar_wip/refine-skip-retime.tsv).
- Feature build: [`columnar_wip/bench-feature-sync.py`](columnar_wip/bench-feature-sync.py), both engines, writing [`columnar_wip/refine-skip-feature.tsv`](columnar_wip/refine-skip-feature.tsv).
- Tables: [`columnar_wip/assemble-hier-gaps.py`](columnar_wip/assemble-hier-gaps.py) builds every table from the TSV that [`columnar_wip/tables-1042.py`](columnar_wip/tables-1042.py) `assembly` writes, including the OO cells. The REG table comes from `tables-1042.py reg`.

> **This PR makes the within-grandparent refine cheaper (#1388, #1390, #1391).** It has three parts:
> - **#1388: memory networks are scored without a hash map.** `MemCorrection::hierarchicalCorrection` built an `unordered_map` keyed by (module, physical node) on every scoring of a stack. The leaves are now grouped by physical node once, and each physical node's flow per module is summed in a dense scratch. Its comment kept the hash map "since the summation order is part of the reported number"; CLAUDE.md now says bit-identity is never a constraint. The output is bit-identical anyway.
> - **#1390: leaf-layer re-sweeps skip grandparents untouched since the first sweep.** #1389's re-sweeps skipped a grandparent only if its content was what the previous *re-sweep* left. On the leaf layer the first sweep's output now counts too. This is a speed-for-bits trade, taken on Daniel's call.
> - **#1391: one fine-tune pass in the re-sweeps' sub-searches.** A re-sweep starts each grandparent's sub-search from a partial seed of a refined partition. The first sweep keeps the full fine-tune: one pass there made om2_N256_E100k `-d -N1` worse at 6 of 6 seeds (+2.98% in bits at seed 123).
>
> [Per-part attribution](#per-part-attribution) and the options measured and not taken are below; the finding is F81. #1392 (per-grandparent acceptance and web-NotreDame's best L\* trial) is explained in F81 and changes nothing here.
>
> What the snapshot shows:
> - **Codelength changes on 25 of the 332 configurations (41 rows, with the family rows that repeat them). None is more than 0.1% worse in bits.** 22 are higher, by +0.0006% to +0.077% (powergrid `-C -N10`); 3 are lower, by −0.010% to −0.025% (single trials of the overlapping family). Most are the overlapping family at 50k links, where they give back part of #1389's gains: om8_N256_E50k `-C -N10` was −0.190% in bits in #1389 and is +0.067% here.
> - **Instructions summed −2.51% over the 332 configurations.** Over the 295 above 0.3G, the median is −0.72% (5th–95th percentile −12.3% to +0.01%). The bit-identical ones are −1.15% summed, most of it #1388 on memory networks.

> - **Single trials get faster, not slower.** Every changed `-C -N1` row is 6% to 25% faster in seconds, except om2_N256_E50k (unchanged within noise). No bit-identical `-N1` row costs more.
> - **The feature build is bit-identical** in both engines, codelength and `.tree` body.
